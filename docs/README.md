## 🎯 核心问题快速解答

### ❓ 如何切换全文检索和向量检索？

在 `.env` 文件中配置：

```env
# 智能混合模式（推荐）
RAG_STRATEGY=hybrid
RAG_VECTOR_THRESHOLD=5000

# 全文检索模式
RAG_STRATEGY=full_context

# 向量检索模式
RAG_STRATEGY=vector_search
```

**详细说明**: [RAG快速入门指南 - 如何切换检索方式](./RAG快速入门指南.md#⚙️-如何切换检索方式)

---

### ❓ 全文检索和向量检索有什么区别？

| 特性 | 全文检索 | 向量检索 |
|------|---------|---------|
| **原理** | 传输完整文档 | 只传输相关片段 |
| **Token消耗** | 高 | 低（节省60-80%） |
| **准确性** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| **速度** | 慢 | 快 |
| **适用文档** | < 5 页 | > 10 页 |

**详细对比**: [RAG快速入门指南 - 核心概念](./RAG快速入门指南.md#🎯-核心概念全文检索-vs-向量检索)

---

### ❓ 推荐使用哪种模式？

**推荐使用混合模式**：

```env
RAG_STRATEGY=hybrid
RAG_VECTOR_THRESHOLD=5000
```

系统会自动：
- 小文档（< 5000 tokens）使用全文检索
- 大文档（≥ 5000 tokens）使用向量检索

**详细说明**: [RAG快速入门指南](./RAG快速入门指南.md)
