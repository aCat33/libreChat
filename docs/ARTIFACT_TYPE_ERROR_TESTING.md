# Artifact Type Error 修复 - 快速测试指南

## 问题回顾

**症状:** Artifacts生成图表后,预览页面先显示type error,等几秒再点开才出来图表

**根本原因:** Streaming过程中代码不完整就尝试编译渲染

---

```bash
# 确保后端和前端都在运行
npm run backend:dev  # 终端1
npm run frontend:dev # 终端2
```


### 2. 发送测试消息

```

```

### 3. 观察Preview标签

**关键观察点:**

#### 阶段1: AI开始生成
- Artifact按钮应该出现
- 可以点击Preview标签

#### 阶段2: 代码streaming中
- **修复前:** 可能立即显示错误
- **修复后:** 显示 🔄 "正在生成代码..."

#### 阶段3: 代码完成
- **修复前:** 需要手动点击重试
- **修复后:** 自动显示预览 (1秒内)

### 4. 检查UI元素

**加载状态应该包含:**
- ✅ 旋转的加载动画
- ✅ "正在生成代码..." 文字
- ✅ "等待AI完成代码生成" 说明文字

**不应该出现:**
- ❌ "Type Error"
- ❌ "Syntax Error"
- ❌ "Unexpected token"
- ❌ "重试渲染" 按钮 (在正常流程中)

## 问题排查

### 如果仍然看到Type Error:

1. **检查代码类型:**
   ```
   是React组件(.tsx/.jsx)吗?
   → 启发式检查生效
   
   是其他类型?
   → 可能需要扩展检查规则
   ```

2. **检查控制台:**
   ```javascript
   // 查找这些日志
   artifacts: updateArtifact: content.length XXX
   ```

3. **手动验证代码:**
   - 切换到Code标签
   - 查看代码是否完整
   - 是否有明显的语法错误?

### 如果加载提示一直不消失:

1. **检查完整性规则:**
   ```typescript
   // 代码可能无法通过检查
   // 可以临时调整规则的严格度
   ```

2. **查看定时器:**
   ```
   是否有500ms无更新?
   → 应该触发完整性检查
   ```

3. **手动重试:**
   ```
   点击"重试渲染"应该强制渲染
   setIsCodeComplete(true) 被调用
   ```
