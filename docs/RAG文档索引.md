## 🔑 核心概念速查

### 三种 RAG 策略

| 策略 | 环境变量 | 说明 | 适用场景 |
|------|----------|------|----------|
| **全文检索** | `RAG_STRATEGY=full_context` | 传输完整文档 | 小文档、完整上下文 |
| **向量检索** | `RAG_STRATEGY=vector_search` | 只传输相关片段 | 大文档、降低成本 |
| **混合模式** | `RAG_STRATEGY=hybrid` | 自动选择最佳方式 | ⭐ **推荐** |

### 关键环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `RAG_STRATEGY` | `hybrid` | 策略选择 |
| `RAG_VECTOR_THRESHOLD` | `5000` | 向量检索阈值（tokens） |
| `RAG_TOP_K` | `5` | 检索片段数量 |
| `RAG_API_URL` | - | RAG API 地址（必需） |
| `RAG_ENABLE_CACHE` | `true` | 启用缓存 |

### 文档大小参考

| 文档类型 | 估算 Tokens | 推荐策略 |
|----------|-------------|----------|
| 1-3 页 PDF | 500-2500 | 全文检索 |
| 3-5 页 PDF | 2500-5000 | 混合（阈值边缘） |
| 5-10 页 PDF | 5000-10000 | 向量检索 |
| 10+ 页 PDF | 10000+ | 向量检索 |
