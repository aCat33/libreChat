# 文件上传问题修复总结

## 🐛 问题
在同一对话中连续上传不同类型的文件时，AI 回答的仍是第一次上传文件的内容。

**实际案例**：
- 第一次：上传 PNG 图片 → AI 分析图片 ✅
- 第二次：上传 TXT 文本 → AI 仍然分析图片（应该分析文本）❌

## 🔍 根本原因

1. **文件流未关闭**：`createReadStream` 创建的流没有在 `finally` 块中关闭
2. **fileContext 缓存污染**：旧的 `fileContext` 保留在消息对象中，没有被清除

## ✅ 修复内容

### 1. 文件流管理
- ✏️ `packages/api/src/files/text.ts`
- ✏️ `packages/api/src/files/mistral/crud.ts`
- 添加 `finally` 块调用 `stream.destroy()`

### 2. fileContext 清理（关键）⭐
- ✏️ `api/app/clients/BaseClient.js` 
- ✏️ `api/server/controllers/agents/client.js`
- 在添加新 fileContext 前先 `delete message.fileContext`

## 🧪 测试方法

**关键测试**（同一对话中）：
```
1. 上传 image.png → 问"分析这个图片" → AI 回答图片内容
2. 上传 text.txt → 问"分析这个文本" → AI 应该回答文本内容（不是图片）
```

## 📌 关键代码

```javascript
// ✅ 修复前
formData.append('file', createReadStream(file.path)); // 流未关闭

// ✅ 修复后
fileStream = createReadStream(file.path);
formData.append('file', fileStream);
// ...
finally {
  if (fileStream?.destroy) fileStream.destroy(); // 确保关闭
}
```

```javascript

  // 清除旧的 fileContext 防止污染
```
