## 技术细节对比

### Throttle/Debounce时间调整

```typescript
// Artifact更新
优化前: throttle(updateFn, 25)   // 40 updates/sec
优化后: throttle(updateFn, 100)  // 10 updates/sec

// 滚动处理
优化前: debounceRate = 150ms
优化后: debounceRate = 200ms
```

**原因:** 人眼刷新率约60fps (16.67ms),超过100fps的更新是浪费。

### 缓存策略对比

```typescript
// 优化前: 无缓存
const content = LaTeXParsing ? preprocessLaTeX(content) : content;
// 每次都执行正则表达式处理

// 优化后: 智能缓存
if (prevContentRef.current === content && processedContentCache.current) {
  return processedContentCache.current; // 缓存命中,直接返回
}
// 仅在内容变化时处理
```

### React渲染优化

```typescript
// 优化前: className在每次渲染时重新计算
<div className={cn(
  'markdown prose...',
  isSubmitting && 'submitting',
  // ... 多个条件
)}>

// 优化后: 使用useMemo缓存
const containerClassName = useMemo(() => cn(...), [deps]);
<div className={containerClassName}>
```
