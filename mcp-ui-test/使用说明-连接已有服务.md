# 如何连接已有的本地服务

## 📌 核心概念

MCP Server 现在返回的是**纯 iframe 标签**，直接嵌入你已有的本地服务地址，不添加任何额外装饰。

## 🔧 修改步骤

### 1. 找到你的本地服务地址

假设你已经有以下服务运行：
- 船舶报表：`http://localhost:8081/vessel`
- 钻井仪表盘：`http://localhost:8081/dashboard`
- 油井详情：`http://localhost:8081/well/{wellName}`

### 2. 修改 mcp_server.py 中的 URL

打开 [mcp_server.py](mcp_server.py)，找到三个工具的 iframe URL，替换为你的实际地址：

#### 工具 1: get_vessel_report（第 79-96 行）
```python
if name == "get_vessel_report":
    vessel_id = arguments.get("vessel_id", "default")
    
    # ⚙️ 修改这里的 URL
    iframe_html = f"""<!DOCTYPE html>

```

### 3. 更新 librechat.yaml 白名单

添加你的实际服务地址到 `mcpSettings.allowedDomains`：

```yaml
mcpSettings:
  allowedDomains:
    - "http://localhost:8081"      # ✅ 添加你的服务地址
    - "http://127.0.0.1:8081"      # ✅ 也支持 127.0.0.1
    - "http://localhost:12309"     # Mock Server（测试用）
```

### 4. 重启 LibreChat

```bash
# 停止所有 LibreChat 进程
# 重新启动后端
cd d:\work\librechat
npm run backend:dev

# 另一个终端启动前端
npm run frontend:dev
```

## 📋 完整示例

假设你有一个完整的 Web 应用运行在 `http://localhost:8081`：

```
http://localhost:8081/
├── /vessel              ← 船舶报表页面
├── /dashboard           ← 钻井仪表盘页面
├── /well/:name          ← 油井详情页面（动态路由）
└── /api/...             ← API 接口
```

修改后的 mcp_server.py 会直接返回指向这些页面的 iframe，LibreChat 会在对话中渲染它们。

## ⚙️ 高级配置

### 传递查询参数

如果你的服务需要查询参数：

```python
# 示例：传递船舶ID、日期、用户信息等
iframe_html = f"""<iframe src="http://localhost:8081/vessel?id={vessel_id}&date={date}&user=admin"></iframe>"""
```

### 动态路由

如果使用 RESTful 路由：

```python
# 示例：/well/井-A-001
iframe_html = f"""<iframe src="http://localhost:8081/well/{well_name}"></iframe>"""
```

### 身份验证

如果服务需要认证，可以通过 URL 参数或 Cookie：

```python
# 方式 1：Token 参数
iframe_html = f"""<iframe src="http://localhost:8081/vessel?token=YOUR_TOKEN"></iframe>"""

# 方式 2：通过 LibreChat 的用户变量（如果支持）
# 需要在服务端配置 CORS 允许 LibreChat 的 Origin
```

## 🔒 安全注意事项

1. **白名单必须配置**：所有嵌入的域名都必须在 `librechat.yaml` 的 `allowedDomains` 中
2. **CORS 配置**：你的本地服务需要允许 LibreChat 访问（设置 CORS 头）
3. **内网地址**：localhost/127.0.0.1 需要显式添加到白名单
4. **避免敏感信息**：不要在 URL 中传递密码等敏感信息

## ❓ 常见问题

### Q: iframe 显示空白？
A: 检查：
1. 本地服务是否正常运行（浏览器直接访问 URL）
2. `librechat.yaml` 白名单是否包含该地址
3. LibreChat 后端是否已重启
4. 浏览器控制台是否有 CORS 错误

### Q: 如何验证配置正确？
A: 
1. 浏览器直接访问你的服务地址，确认页面正常
2. 检查 LibreChat 后端日志，看 MCP Server 是否启动成功
3. 在 LibreChat 中发送测试消息，查看浏览器控制台的网络请求

### Q: 可以嵌入外部网站吗？
A: 可以，但需要：
1. 外部网站允许被 iframe 嵌入（X-Frame-Options）
2. 添加到 `librechat.yaml` 白名单
3. 注意安全风险
